# Spoon Weather

เว็บดูสภาพอากาศปัจจุบันของเมืองทั่วโลก พื้นหลังเปลี่ยนตามอากาศจริง เขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่ต้อง build และไม่ต้องมี API key

## วิธีรัน

ต้องมี Node.js 20 ขึ้นไป

```powershell
npm start
```

แล้วเปิด http://localhost:3000

- เซิร์ฟเวอร์เปิดให้เข้าได้เฉพาะจากเครื่องนี้ คนอื่นในเครือข่ายเดียวกันเข้าไม่ได้ ต้องเปิดด้วยชื่อ `localhost` เพราะ `127.0.0.1` จะเข้าไม่ได้
- ถ้า `localhost:3000` ถูกใช้อยู่ คำสั่งจะหยุดพร้อมข้อความ `EADDRINUSE` ให้ปิดโปรแกรมนั้นก่อนแล้วรันใหม่
- เปิด `index.html` ด้วยการดับเบิลคลิกไม่ได้ เพราะเบราว์เซอร์ไม่โหลด JavaScript module จากไฟล์ในเครื่องตรง ๆ

## วิธีรัน test

```powershell
npm test
```

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงหน้าเว็บ |
| `style.css` | หน้าตา และสีของท้องฟ้าแต่ละแบบ (`body[data-sky]`) |
| `js/weather.js` | ฟังก์ชันล้วน: สร้าง URL แปลงข้อมูล จัดรูปแบบตัวเลข เลือกพื้นหลังตามรหัสอากาศ |
| `js/app.js` | ยิง API แสดงผล และรับการกดปุ่ม |
| `test/weather.test.js` | test ของ `js/weather.js` |

## ความสดของข้อมูล

แอปนี้ไม่ใช่การวัดสด เป็นค่าล่าสุดจากแบบจำลองอากาศ ไม่ใช่เซนเซอร์ ณ จุดนั้น

- แอปเช็กข้อมูลใหม่ทุก 5 นาที การเช็กนี้หยุดตอนแท็บถูกซ่อน และเช็กทันทีเมื่อกลับมาหลังหายไปนานกว่า 5 นาที
- ข้อมูล "ปัจจุบัน" ของ Open-Meteo แบ่งเป็นช่วงละ 15 นาที ซึ่งเป็นความยาวของช่วงข้อมูล ไม่ใช่รอบที่ได้ข้อมูลใหม่
- นอกยุโรปกลางและอเมริกาเหนือ ค่าราย 15 นาทีเป็นการประมาณจากข้อมูลรายชั่วโมง จึงไม่ใช่การวัดสด
- ปริมาณฝนคือยอดรวมใน 15 นาทีที่ผ่านมา

## แหล่งข้อมูล

- ข้อมูลอากาศจาก [Open-Meteo](https://open-meteo.com/) ภายใต้สัญญาอนุญาต [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) ต้องให้เครดิตแหล่งข้อมูล
- ข้อมูลตำแหน่งเมือง: Location data based on [GeoNames](https://www.geonames.org/)
- แผนฟรีของ Open-Meteo ใช้ได้เฉพาะงานที่ไม่ใช่เชิงพาณิชย์ ถ้าจะใช้เชิงพาณิชย์ต้องเปลี่ยนไปใช้แผนเสียเงิน
- ฐานข้อมูลเมืองไม่มีชื่อไทยของบางเมือง เช่น "นิวยอร์ก" ค้นไม่เจอ แต่ "New York" เจอ
